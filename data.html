Instructions — Read Before You Start

  1. Keep the following ready before you begin:
    1. Approved Programme Name(s), Program Code, Course Title, Course Code, and Scheme (e.g., K)
    2. Course Outcomes (COs), Theory unit-wise content, Lab experiment list, and reference books/websites — ideally drafted in a Word/notepad file first, so you can copy-paste instead of composing on the fly
    3. Names & designations of Course Experts and Industry Experts who reviewed this curriculum
  2. Work top to bottom — Section 1 (Course Information) drives auto-fills elsewhere (e.g., selecting Programme Name auto-fills the Program Code), so fill it first.
  3. Use "+ Add" buttons to add more rows wherever needed (COs, Theory units, Lab practicals, Equipment, Books, Websites, Experts, Assessments) — extra blank rows are fine to leave empty; they're skipped in the final document.
  4. Section IX (Weightage table) auto-syncs with Section V (Theory units) — don't fill it separately; just make sure Section V is complete first.
  5. Save your work often:
    1. Save Data Locally downloads a JSON backup file to your computer.
    2. Save Online stores your data on the server against your Course Code (fill Course Code before using this).
    3. Load Data / Load Online lets you resume a previously saved draft — loading will overwrite whatever is currently in the form, so save first if unsure.
    You'll get a reminder every 20 minutes if you haven't saved — don't ignore it, refreshing/closing the tab without saving will lose your work.
  6. Use Preview / Print to check formatting before finalizing. From there you can:
    1. Print / Save PDF — enable "Headers and footers" in the print dialog for date-stamp and page numbering.
    2. Save as Word (.docx) — for an editable .docx copy.
    3. Clear wipes the entire form — use only when starting fresh, and only after saving your current data.
  7. Fields marked readonly (like Program Code) are auto-generated — don't try to type in them; fix the source field instead (e.g., Programme Name selection).
Section-specific notes:
• Section IV (Teaching-Learning & Assessment Scheme): Enter contact hours, credits, and marks exactly as per the approved scheme — no validation is applied.
• Section XI (CO-PO-PSO Matrix): Use standard correlation levels (1/2/3 or blank) consistently across all COs.
• Section XIV (Question Paper Profile): Fill Unit(T), Level(L: R/U/A), and Marks(M) per bit carefully — the Total Marks should match your Section IV total theory marks.
