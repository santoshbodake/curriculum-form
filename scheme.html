Actions

Excel import: columns must follow the same order as the table above (Sr No, Course Title, Abbreviation, Course Type, Course Code, Total IKS, CL, TL, LL, Self Learning, …). Use Save as Excel / Template to get a correctly laid-out workbook to fill in. Sheets named First Sem., Second Sem., First Year Exit and so on load into the matching stage; any other sheet loads into the stage currently open. Calculated columns in the file are ignored and recomputed.
