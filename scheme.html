How this page works
Every course from the schemes of all departments (six semesters, every elective) is listed once; identical names are grouped automatically. Refresh from Schemes reads the saved-online schemes (and your open programme as it is on the form, including unsaved changes) and updates semester, abbreviation, credits and scheme data; values you edit here by hand are kept. Use Find Similar Names to spot slightly different names, then Merge them — a comment is compulsory. Allocate each course to a department (or Common to all), then Assign Codes, or type a code directly in the New Code column. Code format: YY S D NN = autonomy year, semester, department digit (0 = common, 1–9 = AN, AO, CE, CO, IH, EE, TE, ME, MK), serial.
